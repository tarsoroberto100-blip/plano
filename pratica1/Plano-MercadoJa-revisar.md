# Plano de Teste — MercadoJá

## O sistema (resumo dos requisitos)

O **MercadoJá** é um aplicativo de compras de supermercado com entrega em casa, para Android e iOS. O lançamento está marcado para **segunda-feira, 10/11**.

- **R1:** O cliente faz login com e-mail e senha.
- **R2:** O cliente busca produtos e os coloca no carrinho.
- **R3:** O pagamento é feito por cartão de crédito ou Pix dentro do aplicativo.
- **R4:** O frete é grátis para compras a partir de R$ 100,00; abaixo disso, custa R$ 9,90.
- **R5:** O cliente escolhe uma janela de entrega de 2 horas, entre 8h e 20h.
- **R6:** O cliente acompanha o status do pedido (separando, a caminho, entregue).
- **R7:** A tela inicial mostra um banner com as promoções da semana.
